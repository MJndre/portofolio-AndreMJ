## ✨ Fitur Utama Website

1. **Dual Perspective Mode (Design View vs Code View):**
   - Pengunjung dapat mengganti sudut pandang website antara kacamata *UI/UX Designer* dan *Creative Frontend Coder* secara instan lengkap dengan efek suara synth.
2. **Interactive Design & Code Sandbox:**
   - Eksperimen langsung dengan token warna, border radius, tilt angle, dan shadow neo-brutalist dengan live CSS injection real-time.
3. **Rekam Jejak & Pengalaman (Synced with CV):**
   - Tab switcher interaktif antara **Pengalaman Kerja (Trusmi Group)**, **Pengalaman Organisasi (Himasantika, UKM CE, Mobile Dev)**, dan **Riwayat Pendidikan**.
4. **Dedicated Interactive CV Modal:**
   - Modal tampilan CV lengkap dengan tombol cetak langsung (*Print to PDF*).
5. **Showcase Proyek Nyata:**
   - WebGIS Pemetaan Potensi Desa Ciledug Lor (KKN UMC 2026).
   - Trusmi Group: Internal Mobile Attendance & Dashboard App.
6. **Formulir Kontak & Integrasi WhatsApp:**
   - Tombol chat langsung ke WhatsApp dan copy-email instan.
